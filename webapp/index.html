What this grants — and what it doesn't.

✓
Read bounded text files

UTF-8 only; maximum 64 KiB per read; one directory listing at a time.

✓

Use the allowlist to reduce which relative paths the model can inspect.

×
No writes or shell execution

This tool cannot change source files or run commands.

×

The browser has no connection to the Python process, local filesystem, or CLI session.

DURABLE STATE / 05

Recovery journal.

Inspect run records using the existing SQLite journal commands. No local database is uploaded or read by this webpage.

POLICYFAIL CLOSEDNO AUTO-RESUME
!
Automatic resume is disabled by design.

Unknown execution outcomes and any run with a dispatched tool stay blocked from objective-only restart. A recorded result isn't proof that replay is safe.

01
Start a journalled CLI session

Create local SQLite records for the session and tool boundaries.

python -m interfaces.cli.main --config config/demo.models.json --journal .local/omnitrix.sqlite3
02
List recent runs

Lists IDs and statuses without printing stored objectives.

python -m interfaces.cli.main --journal .local/omnitrix.sqlite3 --list-runs
03
Inspect a run

Replace RUN_ID with a specific run. Inspection is read-only.

python -m interfaces.cli.main --journal .local/omnitrix.sqlite3 --inspect-run RUN_ID
