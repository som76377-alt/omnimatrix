 DURABLE STATE / 05
Recovery journal.
The existing recovery implementation remains conservative. This page documents the supported journal commands instead of fabricating records.
NO AUTO-RESUME

      
!
Unknown outcomes stay blocked.
The recovery policy does not automatically replay tool calls or resume runs whose side effects cannot be verified. Chat sessions in this Studio are in-memory unless durable journaling is explicitly configured.

      

        
01
Start a journalled session
Run in a repository terminal to persist run and tool boundaries.
python -m interfaces.cli.main --config config/demo.models.json --journal .local/omnitrix.sqlite3

        
02
List recent runs
Shows run IDs and statuses without dumping stored objectives.
python -m interfaces.cli.main --journal .local/omnitrix.sqlite3 --list-runs

        
03
Inspect a run
Replace RUN_ID with the exact run identifier.
python -m interfaces.cli.main --journal .local/omnitrix.sqlite3 --inspect-run RUN_ID
